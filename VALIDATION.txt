Correction: validation report

This report previously labeled the project’s mathematical, historical, and cross-cultural claims “complete,” “validated,” and “publication-ready.” Those labels are withdrawn.

The repository contains a proposed finite-state model and software examples. Passing unit tests can show that code behaves as expected on the tested inputs; they do not prove that the model describes the Indus script, establishes a universal validation theorem, or supports historical conclusions about Harappan or other writing systems.

The reported statistics and examples are outputs of project code, not independent archaeological validation. No decipherment, historical finding, formal theorem about all validation systems, or publication acceptance is claimed here. The earlier report is preserved in Git history for audit.
