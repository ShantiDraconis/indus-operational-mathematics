# Sign Families Figures

This directory contains visual representations of Indus sign families and classifications.

## Contents (To be added)

- `family_328_372.pdf` - Stroke signs, jars, and fish signs
- `family_373_417.pdf` - Anthropomorphic, animal, and terminal signs
- `sign_morphology.pdf` - Morphological classification diagrams
- `frequency_heatmap.pdf` - Visual frequency distribution
- `positional_distribution.pdf` - Position preference visualizations

## Figure Generation

Figures can be generated using the Python scripts in the `code/` directory or created manually using drawing tools.

## Format

- Preferred format: PDF or SVG (vector graphics)
- Resolution: 300 DPI minimum for raster images
- Size: A4 or letter size standard
