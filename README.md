> **Status correction:** This repository contains exploratory state-machine and statistical software. It does not decipher the Indus script, prove a universal Harappan formalism, establish claims about Harappan cognition or institutions, or validate applications to law, cryptography, biology, or art. Program outputs and passing tests show only how the implemented model behaves; they do not establish historical or archaeological conclusions. Earlier statements presenting these outcomes as proven or validated are withdrawn.
