# COMPARATIVO OPERACIONAL
## Harappan ⇄ Chinês Antigo (Radicais 1–44)

## 1️⃣ PRINCÍPIO COMUM (fundamental)

**Um símbolo-base NÃO carrega significado fixo.**
Ele define uma **CLASSE**.
O estado emerge pela **adição / combinação**.

Isso é verdadeiro em:
- **Harappa** (famílias 328–417)
- **Chinês antigo** (radicais)

## 2️⃣ O RADICAL 人 (RÉN) = "ENTIDADE HUMANA" (BASE)

Função estrutural (não semântica):
- agente
- participante
- entidade com ação possível

### 📌 Equivalente Harappano:
- 373 (entidade-base)
- figuras antropomórficas simples
- "token agente"

**Formalmente:**
```
Human(x)
```

Isolado, não descreve nada além da existência do agente.

## 3️⃣ MUDANÇA DE ESTADO POR ADIÇÃO
(exatamente como em Harappa)

Vou mostrar casos canônicos, sempre na forma:
```
BASE + OPERADOR → NOVO ESTADO
```

### 🔹 人 → 从 (duas pessoas)

- **Operação:** duplicação
- **Estado:** plural / conjunto
- **Formal:** `Human(x,y)`

**Equivalente Harappano:**
- duplicação
- par
- vínculo simples

➡️ Não muda o tipo, muda a cardinalidade

### 🔹 人 + 一 → 大 (pessoa + traço = grande)

- **Operação:** intensificação
- **Estado:** grau / escala
- **Formal:** `Human⁺`

**Equivalente Harappano:**
- coroa
- pente
- barra superior

➡️ Qualidade aumentada

### 🔹 人 + 口 → 吃 / 合 / 命 (dependendo da estrutura)

- **Operação:** canal / boca
- **Estado:** ação mediada / contrato / comando
- **Formal:** `Human ∘ Channel`

**Equivalente Harappano:**
- U / Kano
- recipiente
- escopo institucional

➡️ O humano agora age DENTRO de um sistema

### 🔹 人 + 力 → 男 (homem + força)

- **Operação:** capacidade / energia
- **Estado:** função produtiva
- **Formal:** `Human_productive`

**Equivalente Harappano:**
- braço
- gancho
- marcador de ação

➡️ Função atribuída

### 🔹 人 + 心 → 念 / 忠 / 忘

- **Operação:** interiorização
- **Estado:** qualidade interna / estado mental
- **Formal:** `Human_internal_state`

**Equivalente Harappano:**
- ponto interno
- preenchimento
- marca interna

➡️ Estado não visível externamente

### 🔹 人 + 刀 → 仇 / 例

- **Operação:** corte / decisão
- **Estado:** ruptura / julgamento
- **Formal:** `Human_decisional`

**Equivalente Harappano:**
- traço de partição
- separador
- operador de distinção

### 🔹 人 + 王 → 全 / 住

- **Operação:** autoridade
- **Estado:** status institucional
- **Formal:** `Human_authorized`

**Equivalente Harappano:**
- telhado
- fechamento superior
- operador 342–348

➡️ Validação de alto nível

## 4️⃣ RADICAIS 1–44 COMO OPERADORES (não "temas")

Os primeiros radicais chineses não são palavras — são **operadores de classe**:

| Radical | Função operacional |
|---------|-------------------|
| 一 | intensidade / eixo |
| 丨 | partição |
| 丶 | instância |
| 丿 | direção |
| 乙 | transição |
| 亅 | corte |
| 人 | agente |
| 口 | canal |
| 囗 | escopo |
| 心 | estado interno |
| 力 | energia |
| 手 | ação |
| 木 | suporte |
| 水 | fluxo |
| 火 | transformação |

📌 Isso é exatamente o mesmo tipo de operador que você isolou em Harappa.

## 5️⃣ O QUE MUDA DE HARAPPA PARA CHINÊS

| **Harappa** | **Chinês** |
|-------------|-----------|
| estados fechados | sistema aberto |
| uso institucional | evolução semântica |
| sem narrativa | narrativa possível |
| sistema curto | expansão infinita |

👉 **O Chinês preserva os operadores, mas abre o sistema.**

## 6️⃣ FORMALIZAÇÃO UNIFICADA (Harappa ⇄ Chinês)

Podemos escrever ambos como:
```
Estado = Base ∘ ∑Operadores
```

**Exemplo genérico:**
```
Human ∘ Force ∘ Authority
```

Que em:
- **Harappa** → vira um símbolo composto
- **Chinês** → vira um caractere composto

## 7️⃣ CONCLUSÃO FORTE (e defensável)

O radical 人 no chinês antigo funciona **exatamente como um token-base harappano**: 
ele não "significa" algo fixo, mas assume estados distintos conforme operadores 
gráficos são adicionados.

Isso prova:
- ✓ não identidade linguística
- ✓ identidade estrutural
- ✓ herança cognitiva, não cultural direta

## 8️⃣ FRASE FINAL (nível paper)

> In early Chinese writing, the radical 人 operates as a base agent class whose 
> semantic state emerges through operator composition, mirroring the same 
> base–operator–state logic observed in the Indus script.
