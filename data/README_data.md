## Data Files

### Sign Inventory

**File**: `derived/sign_inventory.csv`

Columns:
- `symbol_id`: Numeric identifier (1-417)
- `mahadevan_id`: Mahadevan (1977) reference number
- `shape_category`: Inferred morphological class
- `frequency`: Occurrence count in corpus
- `class_hypothesis`: Our inferred semantic class (A1)

**Source**: Mahadevan (1977), Tables I-II  
**License**: CC BY 4.0 (derivative work)

### Frequency Analysis

**File**: `derived/frequencies.csv`

Columns:
- `symbol_id`
- `count`: Total occurrences
- `percentage`: Relative frequency
- `rank`: Frequency rank (1 = most common)
- `cumulative`: Cumulative percentage

**Generated By**: `code/scripts/build_frequencies.py`

### Position Distribution

**File**: `derived/positions_ini_med_fin.csv`

Columns:
- `symbol_id`
- `initial`: Count in initial position
- `medial`: Count in medial position
- `final`: Count in final position
- `percentage_final`: % of occurrences that are final

**Purpose**: Evidence for terminal symbols (A4)

### Bigram Analysis

**File**: `derived/bigrams_topk.csv`

Columns:
- `symbol_1`: First symbol in bigram
- `symbol_2`: Second symbol
- `count`: Co-occurrence count
- `pmi`: Pointwise mutual information
- `compatible`: Whether classes are compatible (A3)

**Purpose**: Validation of composition rules

### Symbol Families

**Files**: `derived/family_*.json`

JSON structure:
```json
{
  "family_id": "26-30",
  "base_symbol": 26,
  "variants": [27, 28, 29, 30],
  "transformations": [
    {"from": 26, "modifier": "dot", "to": 27},
    {"from": 26, "modifier": "stroke", "to": 28}
  ],
  "hypothesis": "Entity family with modifications"
}
```

**Purpose**: Support for symbol family analysis (Chapter 3)

To regenerate all derived data from sources:

```bash
cd ../code/
python scripts/extract_tables.py
python scripts/build_frequencies.py
python scripts/build_bigrams.py
python scripts/detect_families.py
```

This ensures reproducibility.

## Data Limitations

### What's Included

- ✅ Sign inventory (symbols 1-417)
- ✅ Frequency distributions
- ✅ Position analysis (initial/medial/final)
- ✅ Bigram statistics (top 1000)
- ✅ Inferred symbol families

### What's NOT Included

- ❌ Complete raw corpus (copyright/size)
- ❌ High-resolution seal images (available via institutions)
- ❌ Full site-by-site breakdowns (incomplete data)
- ❌ Archaeological context metadata (beyond sign lists)

### Uncertainty

- **Symbol classifications**: Our inferred classes (A1) are hypotheses
- **Frequencies**: Based on published sign lists, not complete corpus
- **Bigrams**: Statistical patterns, not guaranteed semantic relationships
- **Families**: Morphological similarities, not proven relationships

## Using This Data

### For Researchers

1. Check `provenance/sources.yml` for source details

2. Add extraction script in `code/scripts/`
3. Update this README
