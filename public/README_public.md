# Indus Operational Mathematics - Public README

This directory contains **public-facing content** designed for broad dissemination.

## Purpose

The content here is:
- **Accessible**: Written for non-specialists
- **Accurate**: No overclaims or sensationalism
- **Defensive**: Clear about what we do NOT claim
- **Inviting**: Encourages learning and contribution

## Contents

### Core Documents

- **[one_pager.md](one_pager.md)**: Quick overview (1-2 pages)
  - What this project is
  - What we do NOT claim
  - Core concepts
  - Quick links

- **[faq.md](faq.md)**: Frequently Asked Questions (comprehensive)
  - 30+ questions covering common concerns
  - Technical and philosophical questions
  - Misunderstandings addressed

- **[glossary_public.md](glossary_public.md)**: Terminology guide
  - Simplified definitions

### Examples

  - `example_records.json`: Sample data in JSON format

## Intended Audience

- **General Public**: Interested in ancient scripts
- **Journalists**: Seeking accurate information
- **Students**: Learning about formal methods or ancient writing
- **Educators**: Looking for teaching materials
- **Potential Collaborators**: Considering contributing

## What's NOT Here

This public layer does **NOT** include:
- Complete raw data tables (in `/data/`)
- Full mathematical formalisms (in `/model/`)
- Detailed proof code (in `/formal/`)
- Complete bibliography (in `/book/`)

## Using This Content

### For Journalists

**Please**:
- Start with `one_pager.md`
- Read the "What We Do NOT Claim" sections carefully
- Quote the NON-CLAIMS prominently
- Link to the GitHub repository
- Contact us before publishing (optional but appreciated)

**Avoid**:
- Headlines like "Indus Script Deciphered"
- Claims we can "read" or "translate" texts
- Phonetic or linguistic interpretations

### For Educators

**Permissions**:
- All content is CC BY 4.0
- You can use in courses with attribution
- You can adapt diagrams for presentations

**Suggested Use Cases**:
- Examples of formal methods in humanities
- Case studies in comparative paleography
- Lessons on state-based computation

### For Students

**Learning Path**:
1. Start with `one_pager.md` (concepts)
2. Read `glossary_public.md` (terminology)
3. Study `examples/` (concrete cases)
4. Explore `faq.md` (deeper questions)
5. Move to main README.md (technical)
6. Read the book in `/book/` (complete)

## Translating

We welcome translations! Please:
1. Fork the repository
2. Create `public/translations/[language]/` directory
3. Translate `one_pager.md`, `faq.md`, `glossary_public.md`
4. Submit a pull request

Maintain accuracy—do not add claims beyond the English versions.
