% Workflow Notations
\section{Modern Workflow Notation Systems}

\subsection{Business Process Model and Notation (BPMN)}

BPMN provides a formal language for business workflow description.

\subsubsection{Key Components}
\begin{itemize}
    \item Events (start, intermediate, end)
    \item Activities (tasks, subprocesses)
    \item Gateways (decision points, splits, joins)
    \item Flows (sequence, message, association)
\end{itemize}

\subsection{Structural Parallels with Indus}

\subsubsection{Operational Categories}
\begin{center}
\begin{tabular}{ll}
BPMN & Indus Equivalent \\
\hline
Start Event & Instantiation \\
Activity & Entity specification \\
Gateway & Relational operator \\
Data Object & Qualification \\
End Event & Closure \\
\end{tabular}
\end{center}

\subsubsection{Sequence Flow}
\begin{itemize}
    \item BPMN: Arrows connect operations
    \item Indus: Sign order implies sequence
    \item Both: Linear process representation
\end{itemize}

\subsection{Validation and Authorization}

BPMN includes:
\begin{itemize}
    \item Swimlanes (authority/role boundaries)
    \item Authorization points
    \item Validation gateways
    \item Completion markers
\end{itemize}

Analogous to Indus terminal markers and closure operators.

\subsection{Formal Equivalence}

Both systems can be represented as:
\begin{itemize}
    \item State machines (finite automata)
    \item Petri nets
    \item Process algebras
\end{itemize}

\subsection{Differences}

BPMN is more expressive:
\begin{itemize}
    \item Parallel flows (concurrent processes)
    \item Conditional branching (decision points)
    \item Loops and iteration
    \item Exception handling
\end{itemize}

Indus is restricted to linear sequences (DFA limitations).

\subsection{Relevance}

The comparison demonstrates:
\begin{itemize}
    \item Operational notation is a modern, active field
    \item Administrative processes require formal representation
    \item Non-linguistic notation is precise and effective
    \item Validation is central to workflow systems
\end{itemize}

The Indus system is a 4000-year-old workflow notation.
