% Runic and Ogham Systems
\section{Runic and Ogham Notation Systems}

\subsection{Northern European Runic Alphabets}

Runes (Elder Futhark, c. 150--800 CE) show operational characteristics.

\subsubsection{Context}
\begin{itemize}
    \item Carved on stone, wood, metal
    \item Short inscriptions typical
    \item Memorial and ownership markers
    \item Names, titles, brief statements
\end{itemize}

\subsubsection{Operational Features}
\begin{itemize}
    \item Ownership notation: "X owns Y"
    \item Memorial formula: "X made this for Y"
    \item Magical/protective functions
    \item Validation of craft or authority
\end{itemize}

\subsection{Ogham Script}

Irish Ogham (c. 300--600 CE) as operational notation.

\subsubsection{Characteristics}
\begin{itemize}
    \item Linear notation along stone edges
    \item Primarily personal names
    \item Genealogical information
    \item Territorial markers
\end{itemize}

\subsubsection{Formulaic Structure}
\begin{itemize}
    \item Fixed templates: "X son of Y"
    \item Consistent word order
    \item Minimal grammar
    \item Administrative function
\end{itemize}

\subsection{Relevance to Indus}

\subsubsection{Operational Simplicity}
Even phonetic scripts can function operationally:
\begin{itemize}
    \item Restricted vocabulary
    \item Fixed formulae
    \item Administrative purposes
    \item Validation and authentication
\end{itemize}

\subsubsection{Medium Constraints}
Carving on hard materials promotes:
\begin{itemize}
    \item Brevity
    \item Standardization
    \item Formulaic expression
    \item Operational efficiency
\end{itemize}

\subsection{Distinction}

Key difference from Indus:
\begin{itemize}
    \item Runic and Ogham are clearly phonetic alphabets
    \item Represent specific languages (Germanic, Irish)
    \item Can express arbitrary statements (even if rarely)
    \item Linguistic structure evident
\end{itemize}

\subsection{Comparative Insight}

This comparison shows:
\begin{itemize}
    \item Phonetic systems can be used purely operationally
    \item Administrative contexts constrain expression
    \item Brevity is universal in carved inscriptions
    \item Validation function transcends script type
\end{itemize}

The Indus system may be operational whether or not it is phonetic.
